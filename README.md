# ОСНОВА-ПАРСЕР

**Парсер законодательства** — инструмент для автоматического сбора, обработки и структурирования нормативно-правовых актов.

## Назначение

Проект предназначен для извлечения информации из официальных источников законодательства (например, текстов законов, постановлений, приказов) с возможностью дальнейшего анализа или загрузки в базы данных.

## Основные возможности

- Сбор данных с заданных источников (настраиваемые URL)
- Извлечение ключевых полей: дата принятия, номер документа, статус, текст
- Сохранение результатов в структурированном формате (JSON / CSV)
- Логирование процесса парсинга

## Быстрый старт

### Требования

- Python 3.8+
- Установленный `pip`

### Установка

```bash
git clone https://github.com/ваш-репозиторий/osnova-parser.git
cd osnova-parser
pip install -r requirements.txt
Запуск
bash
python app.py
После запуска парсер начнет обработку источников, указанных в конфигурации (по умолчанию — тестовый режим).
